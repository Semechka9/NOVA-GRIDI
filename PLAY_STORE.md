# NOVA GRID: публикация в Google Play

Проект уже подготовлен как PWA: есть `manifest.webmanifest`, offline-кэш, standalone-режим и иконка.

## Быстрый путь

1. Разместить папку проекта на HTTPS-хостинге. Подойдут GitHub Pages, Netlify или Vercel.
2. Открыть опубликованный HTTPS-адрес в [PWABuilder](https://www.pwabuilder.com/).
3. Выбрать Android package name: `com.novagrid.game`.
4. Сгенерировать Android package и скачать `.aab`.
5. Создать приложение в Google Play Console.
6. Загрузить `.aab`, добавить иконку, скриншоты, описание и политику конфиденциальности.
7. Пройти закрытое тестирование, затем отправить приложение на проверку.

## Перед публикацией

- заменить SVG-иконку на PNG 512x512, если упаковщик попросит PNG;
- проверить игру на реальном Android-телефоне;
- добавить страницу политики конфиденциальности, даже если игра не собирает данные;
- сохранить ключ подписи приложения в надёжном месте.
